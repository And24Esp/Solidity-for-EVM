# Solidity-for-EVM
Solidity fundamentals review for reference/potential use in EVM (Ethereum Virtual Machine) product development and management.

I'm going through Alchemy University's Ethereum Developer Bootcamp (https://www.alchemy.com/university/courses/ethereum), and a considerable portion of the whole Bootcamp is dedicated to Solidity. This is the whole curriculum from reference:

Syllabus

1) Blockchain Cryptography: Learning Core Blockchain Cryptography
Bootcamp Introduction: Itemized advice on maximizing your AU learning experience!
The First Primitive: Blockchain and Cryptographic Hashes
Digital Signatures: Verify a Signature Without Revealing a Private Key
Mining & Proof of Work: Intro to Blockchain Consensus Mechanisms
Blockchain Network: How Blockchain Functions as a Network
Week 1 Project: Build a Project with Cryptography

2) Blockchain Storage: Blockchain Balances and Data Structures
Keeping Track of Blockchain User State: How Do Blockchains Keep Track of User State?
Tree Data Structures: Learning to Build and Work with Trees
Blockchain Data Storage: Understanding data storage on blockchains
Week 2 Assignments: A coding project and recap of the week article

3) Ethereum: Diving into the State Machine
Ethereum Features: High Level Overview of Ethereum
Reading Data from Ethereum: Ethereum Clients and the JSON RPC API
Ethereum Transactions: Transactions = Signed JSON-RPC Requests
Front-End Libraries: Ethereum Front-End Libraries
Week 3 Assignments: A Project and Reflections on Week 3

4) Smart Contract Basics: Diving into Solidity Syntax and Data Types
Solidity Syntax: Learning the Basics of Solidity
Functions: Solidity Functions & Visibility
Smart Contract Communication: How Do We Talk to Smart Contracts?
Intro to Hardhat: Hardhat is Here to Help!
Address Interactions: Contracts Communicating with Addresses
Practice Solidity: Put your Solidity skills to the test!
Week 4 Assignments: Challenges and Reflections on Week 4

5) Solidity: Mastering the Solidity Language
Mappings: Revert & Mappings
Events: Events, Logs and Receipts
Escrow Contract: Build an Escrow Smart Contract
Reference Types: Arrays & Structs
Week 5 Project: Lets work on a dapp

6) Solidity Core: The Core Solidity Concepts
Solidity Challenges: Honing Solidity Skills
Multi-Sigs: Learn All About the Features of Multi-Sigs
Inheritance: Contracts That Build on Each Other
ERC-20: The Fungible Token Standard: ERC20
NFTs: Learning Non-Fungible Tokens

7) Solidity Governance: How Smart Contracts are Governed
Proxy Contracts: Delegate to Other Contracts
Libraries: Learn about Solidity Libraries
Upgrading Contracts: Learn Frameworks for Upgrading Contracts
Governance: How Smart Contract Protocols are Governed

8) EVM Chain Certification: Submit a project demonstrating all the skills you've learned in the bootcamp.
